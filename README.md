🛒 Supermarket Sales Forecasting
Developed a sales forecasting model using historical supermarket data extracted from SQL Server. The workflow included:

Data preprocessing: Detected and removed anomalies to ensure data quality.

Applied and compared multiple time series models including Holt-Winters, ARIMA, and SARIMA.

Optimized forecasting accuracy using Prophet with custom seasonality components.

Achieved a MAPE of 18.34%, indicating strong predictive performance.
